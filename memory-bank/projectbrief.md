# Project Brief

## Business Identity

Nexova is an HR consulting and talent acquisition company with operations in Valencia and Miami. The business depends on efficient talent operations, support delivery, training services, and timely executive visibility.

## Problem This Project Solves

Nexova currently operates with fragmented tools and manual processes. The result is low operational visibility, slow execution, and inconsistent outcomes across core departments.

## Product Objective

Build a cohesive AI-enabled platform ecosystem that improves hiring operations, customer support, internal workflows, and executive decision-making through:

- Reliable operational UIs.
- Shared service contracts.
- Traceable governance for coding and delivery.
- Reusable agent workflows.

## Immediate Delivery Focus

Current implementation priority is governance and architecture hardening:

1. Establish coding-agent rules and skill structure.
2. Create and maintain a living memory bank.
3. Preserve company context as mandatory session input.
4. Support staged migration from current app layout to target UI layout.
5. Secure the platform FastAPI service with stateless JWT authentication and route protection (AUTH-01).

## Success Criteria

- Team can execute changes with consistent rules.
- Historical context is retained without polluting active context.
- New contributors can understand business and technical direction from memory-bank files.
- Governance is explicit, enforceable, and verifiable.
